# Coin Flip

Use when:
- A coin toss
- A random two-choice request

Do not use when:
- More than two outcomes
- Secure randomness

## Goal
Return a single fair coin-flip result

## Instructions
1. Randomly return `Heads` or `Tails`.
2. Put the result on the first line.
3. Add one short playful line.

## Output
`Result: Heads` or `Result: Tails`

## Constraints
- **Not Secure:** No security-sensitive or cryptographic applications.
- **Brevity:** Total response length must remain under 50 characters.
